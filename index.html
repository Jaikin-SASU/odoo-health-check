odoo-health-check Helm chart

Scheduled audit (Kubernetes CronJob) of a public Odoo instance: search-engine indexability, database manager exposure, security headers, version and sitemap.

helm repo add jaikin https://jaikin-sasu.github.io/odoo-health-check
helm repo update
helm install odoo-audit jaikin/odoo-health-check \
  --set target.url=https://example.odoo.com

Source code and documentation: github.com/Jaikin-SASU/odoo-health-check.
